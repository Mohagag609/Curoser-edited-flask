# نظام العقارات - Real Estate System

نظام إدارة العقارات الشامل باللغة العربية مع واجهة مستخدم حديثة ومتجاوبة.

## المميزات

### 🏠 إدارة العقارات
- عرض العقارات مع البحث والفلترة
- إضافة عقارات جديدة
- تفاصيل شاملة لكل عقار
- دعم أنواع مختلفة (فيلا، شقة، تجاري)

### 👥 إدارة الوكلاء
- إضافة وإدارة وكلاء العقارات
- معلومات مفصلة لكل وكيل
- سنوات الخبرة ورقم الترخيص

### 📞 إدارة العملاء والاستفسارات
- استفسارات العملاء
- معلومات العملاء
- متابعة الاستفسارات

### 🎛️ لوحة التحكم
- إحصائيات شاملة
- إدارة العقارات والوكلاء
- عرض الاستفسارات

### 🎨 التصميم
- واجهة عربية متجاوبة
- تصميم حديث وجذاب
- دعم الأجهزة المختلفة

## التثبيت والتشغيل

### المتطلبات
- Python 3.7+
- pip

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
cd real_estate_system
```

2. **تشغيل سكريبت البناء**
```bash
./build.sh
```

3. **تشغيل التطبيق**
```bash
source venv/bin/activate
python app.py
```

4. **فتح المتصفح**
```
http://localhost:5000
```

## قاعدة البيانات

النظام يستخدم SQLite مع النماذج التالية:

- **Property**: معلومات العقارات
- **Agent**: معلومات الوكلاء
- **Client**: معلومات العملاء
- **Inquiry**: الاستفسارات

## التقنيات المستخدمة

- **Backend**: Flask, SQLAlchemy
- **Frontend**: Bootstrap 5, Font Awesome
- **Database**: SQLite
- **Language**: Python 3.7+
