# وحدات العقود والأقساط

## نظرة عامة
تم إعادة بناء وحدات العقود والأقساط بالكامل لتوفير نظام احترافي ومتكامل لإدارة عقود البيع والشراء وأقساطها.

## المميزات الرئيسية

### 1. إدارة العقود
- **إنشاء العقود**: نموذج شامل يتضمن:
  - اختيار العميل والوحدة
  - تحديد السعر والمقدم
  - بيانات السمسار والعمولة
  - خيارات السداد (كاش/تقسيط)
  - توليد تلقائي للأقساط

- **عرض العقود**: جدول تفصيلي يعرض:
  - معلومات العميل والوحدة
  - البيانات المالية
  - حالة العقد
  - إجراءات سريعة

- **تعديل العقود**: إمكانية تحديث:
  - الأسعار والمدفوعات
  - بيانات السمسار
  - حالة العقد

- **حذف آمن**: منع حذف العقود المرتبطة بأقساط

### 2. نظام الأقساط
- **توليد تلقائي**: إنشاء أقساط حسب:
  - النوع (شهري/ربع سنوي/نصف سنوي/سنوي)
  - عدد السنوات
  - دفعات سنوية إضافية
  - وديعة الصيانة

- **متابعة الأقساط**:
  - عرض جميع الأقساط مع حالاتها
  - تتبع الأقساط المتأخرة
  - عرض الأقساط القادمة

- **نظام الدفع**:
  - تسجيل المدفوعات
  - ربط بالخزائن
  - إنشاء سندات قبض تلقائياً

## البنية التقنية

### النماذج (Models)
```python
# Contract Model
- id: معرف فريد
- code: كود العقد
- customer_id: معرف العميل
- unit_id: معرف الوحدة
- total_price: السعر الإجمالي
- down_payment: المقدم
- broker_name: اسم السمسار
- broker_percent: نسبة العمولة
- payment_type: طريقة السداد
- status: الحالة

# Installment Model
- id: معرف فريد
- contract_id: معرف العقد
- unit_id: معرف الوحدة
- customer_id: معرف العميل
- amount: المبلغ
- due_date: تاريخ الاستحقاق
- status: الحالة
- type: نوع القسط
```

### المسارات (Routes)

#### العقود
- `GET /contracts/` - عرض جميع العقود
- `GET/POST /contracts/create` - إنشاء عقد جديد
- `GET /contracts/<id>` - عرض تفاصيل العقد
- `GET/POST /contracts/<id>/edit` - تعديل العقد
- `POST /contracts/<id>/delete` - حذف العقد
- `POST /contracts/<id>/installments/generate` - توليد الأقساط

#### الأقساط
- `GET /installments/` - عرض جميع الأقساط
- `GET /installments/<id>` - تفاصيل القسط
- `GET/POST /installments/<id>/pay` - دفع القسط
- `GET /installments/upcoming` - الأقساط القادمة
- `GET /installments/overdue` - الأقساط المتأخرة

### واجهات برمجة التطبيقات (APIs)
- `/api/customers/active` - جلب العملاء النشطين
- `/api/units/available` - جلب الوحدات المتاحة

## دليل الاستخدام

### إنشاء عقد جديد
1. اذهب إلى صفحة العقود
2. اضغط على "عقد جديد"
3. املأ البيانات المطلوبة:
   - اختر العميل والوحدة
   - حدد السعر والمقدم
   - اختر طريقة السداد
4. إذا اخترت التقسيط:
   - حدد نوع التقسيط
   - عدد السنوات
   - أي دفعات إضافية
5. اضغط "حفظ العقد"

### متابعة الأقساط
1. اذهب إلى صفحة الأقساط
2. استخدم الفلاتر للبحث:
   - حسب الوحدة
   - حسب الحالة
   - حسب العميل
3. للأقساط المتأخرة:
   - اضغط "الأقساط المتأخرة"
   - راجع القائمة واتخذ الإجراء المناسب

### تسجيل دفعة
1. اختر القسط المطلوب
2. اضغط على زر الدفع
3. حدد:
   - المبلغ المدفوع
   - الخزنة
   - طريقة الدفع
4. اضغط "تأكيد الدفع"

## الأمان والصلاحيات
- جميع العمليات تتطلب تسجيل الدخول
- العقود والأقساط مرتبطة بالمشروع الحالي
- لا يمكن حذف العقود المرتبطة بأقساط
- جميع العمليات المالية مسجلة في سجل التدقيق

## نصائح وأفضل الممارسات
1. **قبل إنشاء العقد**: تأكد من:
   - توفر بيانات العميل كاملة
   - الوحدة متاحة للبيع
   - الأسعار محدثة

2. **عند التقسيط**:
   - راجع معاينة الأقساط قبل الحفظ
   - تأكد من صحة التواريخ
   - احسب الدفعات الإضافية بدقة

3. **المتابعة الدورية**:
   - راجع الأقساط المتأخرة يومياً
   - تابع الأقساط القادمة أسبوعياً
   - أرسل تذكيرات للعملاء

## استكشاف الأخطاء

### "لا يمكن حذف عقد له أقساط"
- يجب حذف جميع الأقساط أولاً
- أو إلغاء العقد بدلاً من حذفه

### "الوحدة غير متاحة"
- تحقق من حالة الوحدة
- قد تكون محجوزة أو مباعة

### "خطأ في توليد الأقساط"
- تأكد من ملء جميع الحقول المطلوبة
- راجع أن المبلغ المتبقي كافٍ للتقسيط
